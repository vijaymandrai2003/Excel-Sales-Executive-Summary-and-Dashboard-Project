# Excel Sales Executive Summary & Dashboard Project

## Project Overview
This Excel project presents an executive summary of company sales performance, revenue trends, and key business metrics to support clear and data-driven decision-making.

## Dashboard Preview
![Sales Dashboard](Excel%20Project%20Sells%20Executive%20Summary%20Photo.png)

## Key Highlights & Tools Used
* **Data Cleaning & Organization:** Structured raw sales data for accurate analysis.
* **Pivot Tables & Charts:** Created visual summaries for sales performance and trends.
* **Interactive Filters / Slicers:** Enabled quick exploration across dimensions and time periods.
* **Executive KPIs:** Summarized core sales and performance indicators.

## How to View the Project
1. Download the `Excel Project of Company Sells Executive Summary.xlsx` file from this repository.
2. Open the file in Microsoft Excel to inspect the sheets, formulas, and dashboard.
